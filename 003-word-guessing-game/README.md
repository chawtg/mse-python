# Word Guessing Game

A simple command-line word guessing game developed in Python using object-oriented programming (OOP).

## Features

* Randomly selects a word from a predefined list.
* Allows the user to guess one letter at a time.
* Provides 6 lives by default.
* Tracks previously guessed letters.
* Reveals correctly guessed letters.
* Displays the word when the game is won or lost.

## Requirements

* Python 3.x

The project uses only Python standard-library modules, so no external packages are required.

## How to Run

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd word-guessing-game
```

Run the application:

```bash
python word_guessing_game_oop.py
```
