# Temperature Converter

A Python command-line application that converts temperatures between **Celsius and Fahrenheit**. The project demonstrates the use of **Object-Oriented Programming (OOP)** principles, input validation, exception handling, and separation of application logic from user interaction.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* Accept temperature input with a `C` or `F` prefix
* Validate user input
* Handle invalid input using `ValueError`
* Round converted temperatures to two decimal places
* Use a dedicated `TemperatureConverter` class for conversion logic
