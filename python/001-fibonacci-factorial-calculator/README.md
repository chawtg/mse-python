# Fibonacci and Factorial Calculator

## Overview

This is a Python Command-Line Interface (CLI) application that prompts the user to enter a non-negative integer (**N**). The program then:

* Prints the Fibonacci series up to **N**
* Calculates and displays the factorial of **N**

## Requirements

* Python 3.x

No external Python packages are required.

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd python-fibonacci-factorial
```

3. Run the program:

```bash
python main.py
```

## Example

```text
Enter a positive integer (N): 10

Fibonacci series up to 10
[0, 1, 1, 2, 3, 5, 8]

Factorial of 10 is 3628800
```
