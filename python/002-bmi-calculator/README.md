# BMI Calculator

## Overview

This is a Python Command-Line Interface (CLI) application that calculates a user's Body Mass Index (BMI) based on their weight and height. The program also displays the corresponding BMI category.

## Features

* Accepts weight (kg) and height (m) as user input
* Calculates BMI using the standard BMI formula
* Displays the BMI category:

  * Underweight
  * Normal weight
  * Overweight
  * Obese
* Validates user input and handles invalid entries

## Requirements

* Python 3.x

No external Python packages are required.

## How to Run

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd bmi-calculator
```

3. Run the program:

```bash
python fibonacci-factorial-calculator.py
```

## Example

```text
=== BMI Calculator ===

Enter your weight (kg): 68
Enter your height (m): 1.61

Result
----------------
Your BMI is: 26.23
Category: Overweight
```
